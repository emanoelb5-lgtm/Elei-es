# Eleições 2026 — Termômetro Presidencial

Aplicativo Android experimental que combina sinais de pesquisas eleitorais, agregadores públicos e mercados de previsão para estimar probabilidades de vitória na eleição presidencial brasileira de 2026.

> **Aviso:** não é pesquisa eleitoral, não é previsão oficial e não recomenda voto ou aposta. As probabilidades são estimativas experimentais sujeitas a erro.

O projeto é atualizado automaticamente e mantém histórico público das leituras para comparação.
